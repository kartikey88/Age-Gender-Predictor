# Age & Gender Predictor

A deep learning application that predicts approximate
age and gender from facial images.

## Features
- Upload photos
- Capture photos using webcam
- Face detection using OpenCV
- Age prediction
- Gender prediction
- Confidence visualization

## Technologies
- Python
- TensorFlow
- Keras
- ResNet50
- OpenCV
- Streamlit
- NumPy

## Installation

Install dependencies:

pip install -r requirements.txt

## Run

streamlit run app.py

## Model Required

age_gender_model_ft.keras

Keep the model in the same folder as app.py.

## Disclaimer

Age is an estimate and predictions may be inaccurate.
For educational purposes only.
